# سجل المعلمين

نسخة نظيفة من سورس تطبيق تسجيل بيانات المعلمين (الأزهر الشريف).

فيها الفورم، الرقم المسلسل، السجل، الطباعة، الإكسل، والواتساب. من غير ملفات جروك.

## التشغيل

```bash
npm install
npm run dev
```

يفتح على http://localhost:8080

- `/` فورم التسجيل
- `/record` سجل الإدارة

## قاعدة البيانات

من غير `DATABASE_URL` البيانات تتخزن محليًا أثناء التطوير.

للنشر الحقيقي (Vercel أو أي استضافة):

1. أنشئ قاعدة Postgres من https://neon.tech
2. ضع المتغير:

```
DATABASE_URL=postgres://USER:PASSWORD@HOST/DB?sslmode=require
```

3. `npm run build`

بعدها الموقع يبقى لينك عادي مش مربوط بجروك.
